GuardBand

Open this link on your phone

Password resets for GuardBand finish inside the app, so this link has to be opened on the phone where GuardBand is installed.

  1. Open your email on that phone.
  2. Find the GuardBand password reset message.
  3. Tap the link in it. GuardBand will open on the new password screen.

Reset links expire, and each one can only be used once. If nothing happens, request a new link from Forgot Password? on the GuardBand sign-in screen.
